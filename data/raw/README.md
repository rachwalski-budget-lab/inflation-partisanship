# Raw Data

The Pew ATP files are not included in this repository. Pew provides them at no
cost to users with a Pew Research Center account.

To obtain them:

1. Create an account at pewresearch.org and accept the ATP terms and
   conditions.
2. Download the SPSS (`.sav`) file for Waves 101, 107, 110, 116 and 120. The
   download pages are listed in `DATA_SOURCES.md`.
3. Place the files in this folder as shown below. The folder and file names are
   set in `config.yml`.

```
data/raw/wave data/
├── w101_jan22/ATP W101.sav
├── w107_aprl22/ATP W107.sav
├── w110_jun22/ATP W110.sav
├── w116_oct22/ATP W116.sav
└── w120_jan23/ATP W120.sav
```
