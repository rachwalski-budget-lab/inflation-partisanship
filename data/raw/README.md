# Raw data (not included)

The analysis uses five waves of the Pew Research Center American Trends Panel
(ATP). Pew distributes these files to registered users under its terms of use,
so they are not included in this repository.

To obtain them:

1. Create a free Pew Research Center account at pewresearch.org and accept the
   ATP terms and conditions.
2. Download the SPSS (.sav) file for each wave:
   Wave 101 (Jan. 2022), Wave 107 (Apr. 2022), Wave 110 (Jun. 2022),
   Wave 116 (Oct. 2022) and Wave 120 (Jan. 2023).
3. Place them in this folder with the following structure (folder and file
   names are set in `config.yml`):

```
data/raw/wave data/
  w101_jan22/ATP W101.sav
  w107_aprl22/ATP W107.sav
  w110_jun22/ATP W110.sav
  w116_oct22/ATP W116.sav
  w120_jan23/ATP W120.sav
```
